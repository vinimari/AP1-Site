Sobre o Sistema de Cadastro

Sistema para gerenciar todos os shinobi registrados em nossa aldeia.

Objetivos do Projeto

Organização de Ninjas

Manter um registro centralizado de todos os ninjas da Vila da Folha, desde gennins iniciantes até jounins experientes e kages lendários.

Gerenciamento de Informações

Registrar dados essenciais como nível de ninja, especialidade, equipe/squad e outras informações importantes para organização das missões.

Como o Site Funciona

Este sistema foi desenvolvido com HTML5, CSS3 e JavaScript puro, sem depender de servidores ou frameworks complexos. Todos os dados do formulário são processados no navegador do cliente.

O site utiliza o método GET para transmitir dados através da URL, permitindo que você veja exatamente quais informações estão sendo enviadas. Isso é ideal para fins educacionais e demonstrações.
